# UI/UX
- Avoid sparkle/magic icons and emojis in the UI. Use standard, clean icons instead. Confidence: 0.70
- Prefer horizontal swipeable cards for content browsing over vertical lists where practical. Confidence: 0.65
- Prefer GitHub-style heatmap grids over numeric stats for activity/streak displays. Confidence: 0.70
- Do not truncate text content anywhere (bodies, subtitles, key takeaways, sources). Show full content. Confidence: 0.75
- Do not use em dashes in copy. The user explicitly dislikes them across all pages. Confidence: 0.80
- Match design language (colors, fonts, curves, softness) from the landing page across all other pages (blog, feed, profile, etc.). Confidence: 0.80
